# Reconstruction

Run from the repository root. The public build is:

```bash
source /workspace/cloud-setup/activate.sh
cmake -S die -B work/build-die -DCMAKE_BUILD_TYPE=Release
cmake --build work/build-die --parallel 2
ctest --test-dir work/build-die --output-on-failure
```

Copy `os_lifecycle_runtime_validation.sh` here to
`work/os_lifecycle_runtime_validation.sh` before executing it: its working
paths are intentionally relative to that location. It compiles the offline
driver and validates complete/capped slot ownership and one L/C/S flow each.
Then run the independent exact check:

```bash
python3 die/validation/os_lifecycle_runtime_oracle.py \
  --driver work/os_lifecycle_runtime_driver \
  --output work/os-lifecycle-20261014/runtime-readiness-oracle.json
```

This driver is not used by production compile/estimate, has no cycle skipping,
and the cap counts submissions rather than Runtime LP pivots/internal events.
The checker independently manages readiness but consumes the compiler's work
facts. It does not independently validate source hardware or all byte formulas.

`identity_driver.cc` can be compiled against a before/after static library with
`-I die/include -I astra-sim-wscllm/extern/helper`. It captures 62 selected task
hashes/summaries, including both matrix paths, storage types, repeated passes,
and fractional coefficients. The saved identity comparison is a compatibility
regression for that finite set, not whole-domain equivalence.

The LRU manager runner needs its official et_def.proto generated by protoc
3.21.12. See evidence `lru-manager/schema-generation.txt`; adjust the runner's
REPO path for another environment. It preloads the generated work-tree module
and leaves real generator/routing code active. No dependency stub substitutes
for Chakra or remote transfer behavior.

The LRU audit describes the C++/Python protocol port's required differences.
Base Online evidence carries the actual command/binary/source identities in
`../../evidence/os-foundation-20261014/base-online/`; do not attribute that run
to later worktree edits.

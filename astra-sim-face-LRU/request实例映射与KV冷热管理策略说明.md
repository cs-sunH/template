# FACE-LRU 策略说明：请求实例映射与 KV 冷热管理

> 本文从体系结构、算法—软件映射与仿真三个视角，给出本仓（astra-sim-face-LRU）
> 策略的通用说明。全文与具体硬件配置、模型规格无关：拓扑规模、算力/带宽/容量、
> 模型层数与维度等均以参数符号表达，任何满足前提的晶圆级系统都可套用。

## 1. 策略定位

本仓是 `astra-sim-face` 的 **KV 冷热管理改造仓（-LRU）**，在版本演化链
（WSC-LLM → FACE → SH-1.0 → SH-2.0 → SH-3.0）之外取"组合"路线：

- **映射逐行保留 FACE**：请求→实例映射与原仓 `astra-sim-face` 完全一致
  （两阶段独立选点、负载与邻域感知），一行未改；
- **KV 冷热管理承袭 SH-2.0 并去类型化**：把原仓"两态 KV（驻留/删除）+
  LRU 零代价删除 + 历史全量重算"整体替换为**三态冷热管理**——LOCAL /
  PARTIAL（前 ⌈L/2⌉ 层片上 + 后 ⌊L/2⌋ 层远端）/ REMOTE，逐出/回迁/恢复的
  内核与物理发射链路取自 sh_2.0，但**删除类型化区分**（sh_2.0 的"human 类
  先于 tool 类"四段式被裁剪为无类两段式）、**不设消融档位**（逐出行为唯一）、
  **不设 R_kv 保留水位**、**完成路径零逐出**；
- **恢复取代重算**：历史 KV 不再重算——被逐出的会话落在远端冷层，下一轮
  按需回迁（PARTIAL 只回迁后缀并与前缀计算真流水重叠）；RECOMPUTE 路径已
  从历史决策中删除。

与 sh 系的明确对照：

| 维度 | 本仓（FACE-LRU） | sh_2.0 | sh_3.0 |
| --- | --- | --- | --- |
| 映射 | FACE 原始映射（两阶段独立选点，不感知 KV） | 负载均衡映射（历史 KV 状态进入统一目标） | 一次映射（KV 位置为映射第一约束） |
| 逐出 | 去类型化两段式 LRU | 类型化两段式（human 先于 tool） | 类型化两段式 |
| 恢复 | 远端回迁（PARTIAL 真流水） | 远端回迁（真流水） | 远端回迁（真流水） |
| R_kv 水位 | 明确不实现 | 文档有、代码无（本仓对齐 sh 代码行为） | 文档有 |

## 2. 系统模型与记号

### 2.1 体系结构前提

- **晶圆级芯片**：R 行 × C 列二维 Mesh，N = R·C 个 NPU；
- **每 NPU**：峰值算力 F；本地 HBM 带宽 B_HBM、访问时延 λ_HBM、容量 C_HBM；
- **片间链路**：相邻 NPU 间带宽 B_NOC、逐跳时延 λ_NOC；
- **远端内存池**：网格边界 NPU 为**边缘 NPU**，各挂一个远端端口（带宽 B_rem、
  时延 λ_rem），全体端口构成逻辑统一的 KV 池（统一逻辑地址空间：从边缘
  NPU A 写入的数据可从另一边缘 NPU B 读出）。远端池**无容量上限、无自身置换**
  ——它是冷层终点而非缓存。每个边缘端口为严格 FIFO 单事务队列，单次访问
  `耗时 = λ_rem + 字节数 / B_rem`，端口之间完全并行。

### 2.2 实例池与邻接图

芯片被划分为 m 个**互不重叠、铺满整片、等大的轴对齐矩形实例**，每实例
t 个 NPU（TP = t）。所有实例身份对等，同时承担 Prefill 与 Decode（统一
实例）。实例间共享物理边即邻接，构成带边权的实例图：边权初始为 1（跳数），
图中两实例的**加权距离**取最短路。

**可调度距离上限**（Decode 选点的算法核心参数，源自 FACE 论文的设计准则）：

> D_limit = B_NOC / B_HBM

即"实例间链路带宽相对本地内存带宽的倍数"。它表达了这样的工程判断：若
Decode 实例离 Prefill 实例太远，跨实例 KV 交接的片上传输时间将超过直接从
本地 HBM 重读的时间，交接便不划算。由于 B_NOC > B_HBM，D_limit 是大于 1
的实数；在边权为 1 的实例网格上，它等价于"允许 1~2 跳的邻域"。

### 2.3 模型与 KV 容量记号

设模型 L 层、隐藏维 d、注意力头数 H、元素字节 b：

- 每 token KV 字节数 B_KV = 2·L·d·b；层区间 [l₀, l₁) 的 KV 与层数成正比；
- 注意力头按**整头**划分到 t 个 NPU（H 不整除时前若干 NPU 各多一头），
  同一会话在各 NPU 上的 KV 分片可以不等——**容量检查逐 NPU 进行**；
- 层区间分片逐 NPU 按整头规则折算，与全量**严格守恒**（本地 + 远端账面
  逐字节等于会话总额）；
- 逐 NPU 账本：剩余 = C_HBM − 权重分片 − 驻留分片（含层区间折算）−
  预留分片；
- 本仓**不设** KV 保留水位 R_kv（容量判定只看逐 NPU 净剩余）。

### 2.4 负载记号

会话多轮：首轮带绝对到达时刻，后续轮在"上轮 Decode 完成 + 思考间隔"后
到达。每轮派生量：h_hist（上轮最终上下文）、h_pre = h_hist + 本轮输入、
h_fin = h_pre + 生成长度。预填充按 p_chunk（参数）分块。

## 3. 请求实例映射策略（FACE 原始映射，零改动）

### 3.1 Prefill 阶段选择（请求到达时）

在全部 m 个实例中取排序键字典序最小者：

> **（队列中全部请求的剩余预填充块数之和， 最近一次承接新请求的时刻， 实例编号）**

三级平局规则：

1. 剩余块数最少者优先（负载均衡主键——比 WSC-LLM 的"请求数"更精细，长请求
   贡献更多块数）；
2. 块数相同 → 最近承接时刻最早者优先（最久没接到新活的实例优先；从未承接过者
   视为最早，最优先）；
3. 仍相同 → 实例编号最小（等大实例下纯属确定性破平，保证结果可复现）。

每个实例内部是 FCFS 队列；同一时刻多个请求到达时逐个处理，每个请求都对
全实例做一次快照后再选择。

### 3.2 Decode 阶段选择（Prefill 完成边界）

某个请求的预填充全部完成后，**独立地**为其选择 Decode 实例：

**第一步：邻域过滤。** 候选集 = 与该 Prefill 实例加权距离 ≤ D_limit =
B_NOC/B_HBM 的实例（含自身）。

**第二步：增量代价评估。** 对每个候选 j，用预测模型比较"加入本请求前后"
的一次混合迭代时长：

- 当前状态：(是否有预填充工作， 活跃解码批大小 b_j， 批内最长上下文 ℓ_j)；
- 加入后：(同上， b_j + 1， max(ℓ_j, 本请求预填充上下文 h_pre))；
- **增量代价** Δ_j = T(加入后) − T(加入前)；
- **单位 NPU 代价** = Δ_j / t（按实例规模归一，使不同大小实例可比）。

**第三步：选择与平局。** 取单位 NPU 代价最小者；若出现**精确相等**的多候选，
按实例编号升序列出并以**轮转方式**轮流选取（保证严格平局时负载被均匀轮摊，
而非永远压在编号最小的实例上）。

容量角色是**守门员而非目标**：候选需满足逐 NPU 的可行性（见第 4 节容量
检查），但 HBM 余量不改变代价排序，只淘汰不可行者。**映射不感知 KV 位置**
——会话 KV 的三态与驻留实例只决定恢复成本，不进入任何选择键。

### 3.3 混合迭代调度

选点之后，同一实例内按"混合迭代"推进：

- 实例空闲且（预填充队列非空 或 活跃解码非空）时启动一次迭代；
- **一次迭代 = 队首请求的 1 个预填充块（若有）+ 全部活跃解码请求各推进
  1 个 token**；
- 迭代时长按（是否有块、批大小、批内最长上下文）由预测模型给出；线性层
  部分由"块 token + 批 token"共享，预填充注意力与解码注意力两段重叠取
  较长者；
- 预填充完成的请求立即进入 Decode 准入流程（同轮内后续完成者可见其排队）；
- 解码请求每轮生成 1 个 token，生成长度归零即完成、退出批，并触发同会话
  下一轮的到达计时。

### 3.4 与 WSC-LLM 的关键对照

| 维度 | WSC-LLM | FACE（本仓映射） |
| --- | --- | --- |
| 实例角色 | 物理固定 P/D 分区 | 共享池，逻辑解耦 |
| Decode 归属 | 静态路由唯一确定 | Prefill 完成后动态选点 |
| 选择主键 | 排队请求数 | 剩余块数 / 预测时延增量 |
| 候选范围 | 全部 Prefill 实例 | 加权距离 ≤ B_NOC/B_HBM 的邻域 |
| 网络感知 | 无 | 邻域约束（跳数意义上） |

## 4. KV 冷热管理策略（本仓改造核心）

### 4.1 三态模型

| 状态 | 含义 | 片上层数 |
| --- | --- | --- |
| 完整片上（LOCAL_HBM） | 全部 L 层驻留本实例 | L |
| 部分驻留（PARTIAL_HBM_REMOTE） | 前 ⌈L/2⌉ 层片上 + 后 ⌊L/2⌋ 层远端 | L − ⌊L/2⌋ |
| 完整远端（REMOTE_MEMORY） | 全部层在远端池，无实例归属 | 0 |

层划分按实际模型层数计算：驻留前缀层数 P = L − ⌊L/2⌋（奇数层保留较大半），
**不可配置**；后 ⌊L/2⌋ 层为首个外迁对象（"后缀"）。字节与层数成正比，
半层恰好减半；层区间分片逐 NPU 按整头规则计算，与全量严格守恒。

### 4.2 去类型化两阶段 LRU 逐出

**触发时机**（与 face 原仓完全一致的三处，不新增触发位置）：Prefill 准入
（历史准备）、Decode 准入（P→D 容量交接）、容量增长（prefill/decode KV
增长）；**完成路径零逐出**。

每次逐出调用按以下序执行，**每逐一笔立即逐 NPU 重查水位，够即停**：

- **候选池**：本实例上"已完成（最后完成时刻非空）且非活跃"的驻留会话；
  **不按 human/tool 分类**（无类型化区分）；触发请求自身的会话受保护；
- **排序（LRU）**：（最后完成时刻， 会话标识）升序，平局按会话标识字典序；
- **阶段 1（半层化）**：按 LRU 序把 LOCAL 会话的**后 ⌊L/2⌋ 层**外迁远端
  （remote_store），状态 → PARTIAL；
- **阶段 2（整体外迁 = 唯一回退）**：阶段 1 全部候选半层化后仍不足，才按
  同一 LRU 序把驻留前缀 `[0, P)` **整体**外迁，状态 → REMOTE、清实例归属；
- **逐 NPU 收敛**：实例内**每个 NPU** 同时满足需求才算够；
- **耗尽语义**：两阶段耗尽仍不足 → 记深度缺口（deep_gap）后按 face 语义
  **阻塞推迟 + 容量纪元门重试**（admission_blocked；容量变化或纪元重开
  通道时重试）——只有请求在**空实例**上都放不下才判定配置错误终止，
  不采用 sh 的"耗尽即终止"；
- **守卫**：
  - **D4-I1 受害者资格复核**：逐出循环结束后复查全部受害者确为"已完成
    且非活跃且非保护"的合法候选（防候选快照过期误伤）；
  - **D4-I3 过度逐出守卫**：最后一笔逐出若撤销后仍有一个受影响 NPU 不
    满足需求，则该笔本不必逐——撤销之（保证逐出量最小）；
- **不变量审计**（严格模式 SH_STRICT_KV_INVARIANTS 全量开启）：三态位置
  白名单 / 层域断言 / REMOTE 无实例无驻留层 / 逐 NPU expected_kv 重算 /
  预留一致性。

### 4.3 命中复用与恢复路径（六分支）

下一轮到达、映射照常选点后（**映射不看 KV 位置**），按会话态 × 实例关系
六分支：

| 终态 × 实例关系 | 动作 |
| --- | --- |
| 无历史 | 建片上记录，随预填充增长 |
| 完整片上（同实例） | 零开销本地复用 |
| 完整片上（跨实例） | 整份 KV 按相对 TP 编号配对 NoC 迁移（noc_migrate） |
| 部分驻留（同实例） | **只回迁后缀层段**（remote_load + restore），并与前缀
  计算**真流水重叠**：首 chunk 拆前缀层段/后缀层段，后缀段以远端恢复的
  逐 NPU 完成门为依赖 |
| 部分驻留（跨实例） | **两段链**：前缀 NoC 迁移 + 目标实例容量逐出 + 后缀远端
  恢复；两段承载在**同一条 Prefill 决策记录**内 |
| 完整远端 | **全量回迁**到选定实例（逐目标 NPU 最近边缘端口），到达门 →
  恢复链 → 就绪屏障 → Prefill 主体 |

- **最近边缘 NPU**：对每个源/目标 NPU 分片取曼哈顿跳数最小的边缘端口，
  等距取编号最小；
- **路由**：NoC 段走确定性维度序（XY）最短路由，逐分片记录路径与跳数；
- **按需恢复（非预取）**：恢复仅在下一请求准入时触发；实例空闲时不主动
  拉回已外迁的 KV；
- **恢复容量检查可先于恢复触发逐出**：目标实例装不下时先执行 4.2 的
  两段式逐出再恢复（先容量后恢复的次序）；
- **重算已删除**：`remaining_chunks` 不再含 `ceil(history/p_chunk)` 项，
  历史恢复全部走上述分支。

### 4.4 逐出/回迁物理链路与 HBM 计费地图

每条链路**每字节恰好一次本地 HBM 计费 + 一次池端口 FIFO**，中间 hop 不
发射节点零计费：

| 链路 | 发射序与计费 |
| --- | --- |
| remote_store 链 A（源 ≠ 边缘） | [可选 1B 触发（双端 1B 计费）] → 源 `comm_send(bytes)`
  ＝源端 COMM_READ 唯一数据计费 → 边缘 `comm_recv`（`hbm-charge:false`
  过路零计费）→ 边缘 `mem_store`（池写本地零计费，仅池端口 FIFO）→ 1B
  ack 双端各 1B；**源端收到 ack 后才物理释放** |
| remote_store 链 B（源 == 边缘，直连） | 边缘 `mem_store(bytes, hbm-access-mode:1)`
  ＝POOL_READ 唯一计费 + 池端口 FIFO 双异步汇合 |
| remote_load（回迁） | [1B 控制/请求] → 边缘 `mem_load`（仅池 FIFO）→
  边缘 `comm_send`（`hbm-charge:false`）→ 目标 `comm_recv`
  （`hbm-charge:false`，目标写由 restore 承担防双计）→ 目标
  `local_hbm_kv_restore`（节点级 `is_local_hbm_kv_restore:true`）＝
  RESTORE 唯一数据计费 |
| noc_migrate（LOCAL 跨实例 / PARTIAL 前缀迁移 / P→D 交接） | 按相对 TP
  编号配对 p2p，两端正常 COMM_READ / COMM_WRITE 计费 |

- KV 传输 tag 从高位段（10⁷ 起）单调分配，错开常规通信 tag 段；
- 逐出动作批必须与 watch/列车/其它请求事件同批发射（纯 mem 批不驱动决策
  交付）。

### 4.5 守恒与不变量

- **逐 NPU 账本自洽**：本地 + 远端账面 = 会话总额，逐 NPU 守恒；增量账本
  会话贡献按驻留前缀层段计；
- **终局会话核销**：会话终局（terminal）时按层域减账 + 远端账面静默核销
  （不发传输、**不算逐出**）；
- **无历史截断**、**无 R_kv 水位**、**完成路径零逐出**（三项均为刻意不
  实现，与 sh_2.0 代码行为对齐的裁剪）。

## 5. 算法—体系结构映射分析

1. **邻域约束 ↔ 链路-内存带宽比**：D_limit = B_NOC/B_HBM 把"跨实例交接
   是否划算"编码为图距离约束——链路越快（相对本地 HBM），允许的 Decode
   距离越远。映射决策以一个标量吸收了关键的网络/内存配比，而不必在线
   估计传输时间。
2. **增量时延目标 ↔ Roofline 预测**：解码选点把"新请求加入活跃批"的边际
   代价显式建模：批大小 +1 的线性层增量与"批内最长上下文被拉长"的注意力
   增量，由计算/访存双界预测给出——面向批处理的负载感知。
3. **两段式逐出 ↔ 冷热代价梯度**：阶段 1 只逐后半层——冷数据（后缀层）
   外迁使逐出写流量与回迁读流量都恰好减半，且保留热前缀在片上，同实例
   下一轮只回迁后缀即可恢复；阶段 2 整体外迁是唯一回退，只在半层化全体
   候选仍不够时发生。逐出量由"每笔重查水位 + D4-I3 撤销守卫"压到最小。
4. **映射不感知 KV ↔ 恢复按需化**：本仓与 sh_3.0（KV 位置为映射第一
   约束）构成两极设计——本仓把"KV 在哪里"从映射决策中完全剥离，交给
   六分支恢复按需解决；恢复成本经最近边缘端口与真流水被结构化压缩。
   该组合的正交性使映射行为与原 FACE 仓逐字节可比（消融实验的直接
   对照组）。
5. **边缘端口拓扑 ↔ 统一池语义**：逐分片最近边缘端口 + XY 维序路由 +
   严格 FIFO 端口事务，把"晶圆上离片外存的距离"转化为确定性的逐分片
   传输路径；统一逻辑地址空间使写入端口与读出端口可以不同（外迁经 A、
   回迁经 B），无需数据在边缘之间搬运。
6. **计费地图 ↔ 物理一致性**：每条链路每字节恰一次本地 HBM 计费 + 一次
   池端口 FIFO（链 A 源端读、链 B 直连池读、回迁目标端 restore 写），
   中间 hop 零计费；源端 ack 后才物理释放保证逐出与写入的时序因果。

## 6. 仿真视角

- **双层架构**：Python 策略进程 + C++ 离散事件引擎在线闭环，文件桥协议
  （fail-closed 键集校验）、单在途交付背压；决策边界为到达 / 预填充完成 /
  解码完成 / 请求完成。策略的每次选择都留有全候选证据日志，供离线复盘。
- **在线形态（拼 batch 迭代列车）**：每实例"一个列车在飞"；列车终点 =
  队列头 Prefill drain 或全部 Decode 工作耗尽。逐出触发门：Prefill 准入
  逐出挂到达 gate（恢复链/迁移/就绪屏障之后、Prefill 主体之前）；Decode
  逐出挂列车 post-barrier（drain 后）。PARTIAL 首个 Prefill chunk 拆前缀
  层段与后缀层段两段发射：前缀不等后缀恢复先行计算，后缀以恢复完成门为
  依赖——恢复流量与前缀计算真流水重叠。
- **三段式计算图**：到达段 = 历史逐出 → 历史迁移/读回（PARTIAL 含前缀
  迁移 + 后缀恢复流水）→ 就绪屏障 → Prefill 主体；Decode 段 = 解码逐出 →
  P→D 交接迁移 → 解码迭代；完成段 = 零逐出 + 下一轮到达闹钟。
- **物理模型**：Roofline + 逐 NPU HBM 流体均分（推理 COMP、KV restore
  DMA、NoC p2p 端点读/写、池直连端点共 6 类作业，N 路严格均分 B_HBM，
  事件驱动重分配）；远端端口单事务 FIFO（λ_rem + 字节/B_rem）；拥塞感知
  网络 + 维度序路由；远端写回在源端收到确认后才物理释放空间；节点带
  HBM 计费模式标记（读/写/过路），每字节在正确端点计费一次。
- **可观测指标**：决策日志契约字段——Prefill 行携带
  `history_location_before`（三态）/`history_resident_prefix_layers`/
  `history_transfers`（逐段传输对象：kind/reason/session_id/total_bytes/
  源/目标实例/layer_start/layer_end）与逐出行（`history_evictions`/
  `prefill_evictions`），Decode 行携带 `decode_evictions`；指标层
  `kv_hit_states.csv` 五值域（full/partial/miss/no_history/not_supported，
  完整远端 → full、部分驻留 → partial；full_local 与 full_remote 由
  evidence 列区分）；`cache_events.csv` 逐传输事件（含 remote_store/
  remote_load 的层段与 cause）；HBM 水位离线重放按逐段传输对账（PARTIAL
  两段式恢复不混成标量）；Hop-Bytes 逐分片路径跳数；逐请求时延与吞吐。

## 7. 策略小结

| 维度 | 做法 |
| --- | --- |
| P/D 组织 | 共享实例池，逻辑 P/D 解耦，两阶段独立选点（FACE，零改动） |
| Prefill 选择 | （剩余块数， 最近承接时刻， 实例编号）字典序最小 |
| Decode 选择 | 邻域（距离 ≤ B_NOC/B_HBM）内单位 NPU 增量时延最小；精确平局轮转 |
| 迭代组织 | 混合迭代：1 块预填充 + 全批解码各 1 token |
| KV 层次 | 完整片上 / 前缀片上+后缀远端 / 完整远端，三级（承 sh_2.0） |
| 层划分 | 前 ⌈L/2⌉ 层驻留，后 ⌊L/2⌋ 层首迁；逐 NPU 整头分片守恒 |
| 淘汰 | 去类型化两段式 LRU：（完成时刻， 会话标识），先逐后半层、不足才整体
  外迁（唯一回退）；逐 NPU 收敛，逐笔重查，活跃保护，D4-I1/I3 守卫 |
| 恢复 | 按需（非预取）六分支：本地零开销 / NoC 整迁 / PARTIAL 同实例后缀
  回迁（与前缀计算真流水）/ PARTIAL 跨实例两段链 / 远端全量回迁；重算
  已删除 |
| 水位 | 无 R_kv 保留水位；完成路径零逐出；无历史截断 |
| 容量不足 | admission_blocked 推迟 + 容量纪元门重试；空实例装不下才报错；
  已选定的目标不因容量压力改变 |
| 历史感知 | 映射层无（KV 位置不进决策）；KV 层显式三态 |

一句话概括：**映射保留 FACE（负载 + 邻域 + 边际时延），把"LRU 零代价删除
+ 全量重算"替换为承袭 sh_2.0、去类型化的三态冷热管理——两段式 LRU 逐出先
扫全部会话后半层、不足才整体外迁，恢复按需经最近边缘端口回迁并与前缀计算
真流水重叠；无类型化区分、无消融档位、无 R_kv 水位、完成路径零逐出。**

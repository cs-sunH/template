# SH-3.0 策略说明：请求实例映射与 KV 冷热管理

> 本文从体系结构、算法—软件映射与仿真三个视角，给出 SH-3.0 策略的通用说明。
> 全文与具体硬件配置、模型规格无关：拓扑规模、算力/带宽/容量、模型层数与维度等
> 均以参数符号表达，任何满足前提的晶圆级系统都可套用。

## 1. 策略定位

SH-3.0 是五版本演化链（WSC-LLM → FACE → SH-1.0 → SH-2.0 → SH-3.0）的终点，
把前四版分散的机制统一为**"会话亲和的一次映射"**：

- **P/D 同实例、一次映射**：取消 Prefill 之后的独立 Decode 选点——每个请求只在
  Prefill 准入时选择一次实例，Decode 恒落在同一实例。P→D 的整份 KV 交接从机制
  上消失；
- **映射显式由会话历史驱动**：候选集按会话 KV 的三级状态分流——首请求锚定
  "内部实例"、片上/部分驻留历史粘住驻留实例、远端历史在"边缘实例"中均衡。
  "KV 在哪里、那里放不放得下、那里还有多少计算负载"在同一决策点求解；
- **冷热管理承袭 SH-2.0 的三级层次**：完整片上 / 前缀片上+后缀远端 / 完整远端，
  类型化两阶段 FIFO 逐出，前 ⌈L/2⌉ 层驻留、后 ⌊L/2⌋ 层首迁。

由此，SH-3.0 的研究对象不只是"更精细的缓存置换"，而是**以会话历史、HBM 可行性、
边缘内存拓扑与排队负载共同决定的实例归属问题**。

## 2. 系统模型与记号

### 2.1 体系结构前提

- **晶圆级芯片**：R 行 × C 列二维 Mesh，N = R·C 个 NPU；
- **每 NPU**：峰值算力 F；本地 HBM 带宽 B_HBM、访问时延 λ_HBM、容量 C_HBM；
- **片间链路**：相邻 NPU 间带宽 B_NOC、逐跳时延 λ_NOC；
- **远端内存池**：网格边界 NPU 为**边缘 NPU**，各挂一个远端端口（带宽 B_rem、
  时延 λ_rem），全体端口构成逻辑统一的 KV 池。

**实例的边缘属性**（本策略新增的拓扑分类）：一个实例若**不含任何边缘 NPU**
称为**内部实例**（离片外存最远、远端流量最少）；若含至少一个边缘 NPU 称为
**边缘实例**（恢复/外迁路径最短）。在典型的"矩形实例铺满网格"布局下，内部实例
唯一且位于晶圆中心，其余均为边缘实例。

### 2.2 实例池

m 个**互不重叠、铺满整片、等大的轴对齐矩形实例**（每实例 t 个 NPU，TP = t），
全部对等承担 P 与 D（同一实例可同时运行队首预填充与活跃解码批）。本策略**不再
使用实例间距离限制**（FACE 遗留的邻域约束被取消——因为不再有 P→D 跨实例交接）。

### 2.3 模型与 KV 容量记号

设模型 L 层、隐藏维 d、注意力头数 H、元素字节 b：

- 每 token 全模型 KV 字节数 B_KV = 2·L·d·b；层区间 [l₀, l₁) 的 KV 与层数成正比；
- 注意力头按**整头**划分到 t 个 NPU（不整除时前若干 NPU 各多一头），分片逐 NPU
  不等——**容量检查逐 NPU 进行**；
- 逐 NPU 账本：剩余 = C_HBM − 权重分片 − 驻留分片（含层区间折算）− 预留分片；
- **KV 保留水位**（参数 R_kv）：逐 NPU 为"R_kv token 完整 KV"保留空闲。

### 2.4 负载记号

会话多轮，首轮绝对时刻到达、后续轮"上轮完成 + 思考间隔"到达；每轮可声明输入
前缀，可复用历史 = min(输入前缀, 上轮最终上下文)，超出部分重算；h_pre、h_fin
与预填充分块 p_chunk 同前各版。

## 3. 请求实例映射策略（核心：一次映射的三段式分流）

### 3.1 P/D 同实例

每个请求在 Prefill 准入时选定唯一实例 i，之后固定 **i_D = i_P**：预填充形成的
KV 直接留在原实例进入解码，**不发生任何 P→D 迁移**（交接动作退化为零字节的本地
复用）。实例内仍按混合迭代组织：队首预填充块与活跃解码批同迭代推进。

### 3.2 候选集：逐 NPU HBM 可行性

对每个实例 i、每个 NPU q：

> required = h_fin 的完整 KV 分片 − 会话已驻留本实例的分片
> reclaimable = 净剩余 + 可淘汰冷会话的驻留分片
> **可行 ⇔ ∀q：reclaimable ≥ required**

**部分驻留会话的硬亲和**：可行性掩码直接把非驻留实例判为不可行。

**等待语义（不扩候选集）**：目标候选集当前全不可行时，若"腾空后可行"（分片 ≤
C_HBM − 权重），请求留在等待队列、在后续决策点重试；只有当请求在**空实例**上都
放不下时才判定配置错误并终止。**任何情况下候选集都不因等待而扩大。**

### 3.3 三段式选择规则

按会话 KV 状态分流（每段都以 3.2 的可行性为前提）：

**分支 1——会话首请求（无历史）**：候选 = 可行实例 ∩ **内部实例**（不含边缘
NPU）。在候选中按服务时间负载均衡（见 3.4）选择。
- 设计意图：新会话尚无 KV，把宝贵的边缘位置留给迟早要外迁/恢复的老会话；首请求
  从内部起步，未来外迁时自然向边缘扩散；
- **拓扑退化**：若布局中不存在内部实例（如实例划分使所有实例都含边界 NPU），
  显式退化为"全部可行实例中负载均衡"，并记录退化原因。

**分支 2——完整片上或部分驻留历史**：**强制绑定驻留实例**，不做负载比较。
- 完整片上 → 本地零开销复用；部分驻留 → 同实例恢复远端后缀再合并；
- 驻留实例暂不可行 → 请求等待，容量变化后重试；**不迁移、不重建、不换实例**。

**分支 3——完整远端历史**：候选 = 可行实例 ∩ **边缘实例**（含边缘 NPU 的实例）。
在候选中按服务时间负载均衡选择，然后执行全量远端恢复。
- 设计意图：远端读回必须经边缘端口，把恢复流量钉在边缘实例上，避免远端数据
  再穿透半个晶圆落到内部实例；同时恢复后的 KV 自然驻留在边缘，为下一轮可能的
  外迁缩短路径。

### 3.4 负载目标与平局规则

分支 1 与分支 3 的均衡目标为最小化实例服务时间负载：

> **L_i(t) = L_run + L_queue + L_decode**
>
> - L_run：在飞预填充请求的剩余时间（Roofline 逐块估计；在线无块级进度事件时
>   取全量上界近似）；
> - L_queue：排队预填充请求逐块估计求和（不含在飞者，避免双计）；
> - L_decode：每个活跃解码请求的剩余时间——期望剩余 token = **平均生成长度 −
>   已生成**（负载级统计的冻结常数，不预知单请求真值），从当前上下文起逐 token
>   估计求和。

**平局规则**：（L_i， 最近承接时刻（无者视为最早）， 实例编号）字典序最小。

注意：**远端恢复的传输代价不进入 L_i**——恢复在选点之后执行（按需恢复），选点
只看计算负载与可行性；恢复路径由最近边缘端口规则独立确定。

### 3.5 决策时机与事件序

同一决策批内：先处理完成类（其中先预填充完成、后解码完成；完成处理内先登记
全部完成、再统一恢复水位），后处理到达类（按输入序），最后统一执行准入与发射。
同时刻到达按负载输入的既定顺序逐个快照选点。

## 4. KV 冷热管理策略

### 4.1 三态模型（承 SH-2.0）

| 状态 | 含义 | 片上层数 |
| --- | --- | --- |
| 完整片上（LOCAL） | 全部 L 层驻留本实例 | L |
| 部分驻留（PARTIAL） | 前 ⌈L/2⌉ 层片上 + 后 ⌊L/2⌋ 层远端 | ⌈L/2⌉ |
| 完整远端（REMOTE） | 全部层在远端池 | 0 |

层划分按实际模型层数计算（奇数层保留较大半），层区间分片逐 NPU 按整头规则
计算，与全量严格守恒；字节与层数成正比，半层恰好减半。

### 4.2 类型化两阶段 FIFO 逐出

逐出顺序：先按触发请求的会话类型类（如人类类 → 工具类，由负载声明的下一轮触发
类型标记，无声明者归人类类），每类内两阶段，**每次逐出后立即重查逐 NPU 水位**：

- **阶段 1（半层化）**：最早完成的完整片上非活跃会话 → 仅外迁后 ⌊L/2⌋ 层，
  状态 → PARTIAL；
- **阶段 2（整体外迁）**：该类全部可半层化者已减半仍不足 → 把片上前缀整体
  外迁，状态 → REMOTE。

- 类内 FIFO：（最后完成时刻， 会话标识）升序，平局按会话标识字典序；
- 候选资格："已完成且非活跃"的本实例驻留会话；触发请求自身被保护；
- 逐 NPU 收敛；耗尽仍不足则报错；
- 触发时机：准入、历史准备、解码预约/增长、预填充增长、完成后水位恢复（逐 NPU
  检查剩余 ≥ R_kv 分片）。

### 4.3 命中复用与恢复路径

| 终态 | 动作 |
| --- | --- |
| 新会话 | 建片上记录，随预填充增长 |
| 完整片上（同实例，由分支 2 保证） | 零开销本地复用 |
| 部分驻留（同实例） | **只恢复远端后缀层段**，合并为完整片上 |
| 完整远端 | 分支 3 选定边缘实例后**全量恢复** |

- **最近边缘 NPU**：对每个目标 NPU 分片取曼哈顿跳数最小的边缘端口，等距取
  编号最小；
- **路由**：确定性维度序（如先列后行）最短路由，逐分片记录路径与跳数；
- **按需恢复（非预取）**：恢复仅在下一请求准入时触发；实例空闲时不主动拉回已
  外迁的 KV；
- **流水化恢复**：部分驻留会话的首个预填充块拆为前缀层段与后缀层段，后缀段以
  远端恢复的逐 NPU 完成门为依赖，恢复流量与前缀计算重叠；
- **退化归一**：截断后可复用历史为 0 且处于部分驻留态 → 归一化为完整片上空
  会话。

### 4.4 上下文截断与 KV 单调性

到达时按声明前缀截断会话账本（片上按差额回收分片，远端仅核销账面）；活跃会话
禁止截断；预填充/解码阶段 KV 单调增长至 h_fin，不收缩。

## 5. 算法—体系结构映射分析

1. **一次映射 ↔ 消除 P→D 交接**：前四版中两阶段独立选点天然产生"整份 KV 跨
   实例搬运"的流量。P/D 同实例把这股流量从机制上归零——代价是 Decode 无法再
   独立寻找边际代价最小的实例。收益/代价的权衡依据是：多轮会话负载中，会话 KV
   的搬运（可能数百 GiB）远比单次解码批的边际时延差异重要。
2. **三级分流 ↔ 边缘内存拓扑的显式利用**：内部实例（远端流量最少）承接新会话、
   边缘实例（恢复/外迁路径最短）承接远端历史的恢复、驻留实例承接粘性历史——
   三类候选集把"晶圆上离片外存的距离"这一拓扑属性变成了映射约束。远端数据流
   呈现"从边缘进入、向中心沉淀、按需回边缘"的单向循环。
3. **粘性亲和 ↔ 恢复成本的结构化**：分支 2 把"历史在哪"升格为硬约束：完整驻留
   会话零迁移复用，部分驻留会话只拉后缀。加上半层外迁优先，会话的典型生命周期
   成为"片上增长 → 半层化（腾空间）→ 同实例恢复后缀 → 再增长"，任何一步都不
   跨实例搬运整份 KV。
4. **等待而非扩集 ↔ 可行性与活性的分离**：目标实例满员时请求等待，候选集不
   扩大。这保证亲和性不被"临时容量压力"稀释——代价是可能的首请求排队延迟
   （内部实例是单点）。系统以 R_kv 水位与两阶段逐出维持每个实例的接纳余量，
   缓解该风险。
5. **负载估计的可实现性**：L_i 的解码剩余用负载级平均生成长度（冻结常数）、
   在飞预填充取上界近似——决策只依赖冻结输入与已发生事实，不做预知、不做在线
   增量统计，保证同输入同决策的可复现性。

## 6. 仿真视角

- **双层架构**：Python 策略进程 + C++ 离散事件引擎在线闭环，文件桥协议、单在途
  交付背压；决策边界为到达 / 预填充完成 / 解码完成 / 请求完成，完成时解码完成与
  请求完成成对触发。策略的每次选择都留有全候选证据日志（可行性掩码、负载快照、
  亲和原因、等待时长），供离线复盘。
- **一次映射的在线形态**：预填充完成边界不再执行 Decode 搜索，直接原地进入解码
  发射；实例的"忙"语义为"一个预填充整段在飞"，解码段不受忙门限制（由同一 NPU
  的物理串行链自然排序）——一个实例同一时刻可承载"1 个在飞预填充段 + 多个在飞
  解码段"的混合迭代。
- **三段式计算图**：到达段 = 历史逐出 → 历史迁移/读回（部分驻留含前缀/后缀
  流水）→ 就绪屏障 → 预填充整段（逐块聚合）；解码段 = 解码逐出 →（本地交接，
  零字节）→ 解码整段（逐 token span）；完成段 = 完成逐出 → 下一轮到达闹钟。
- **物理模型**：Roofline + 逐 NPU HBM 流体均分（恢复 DMA、通信读写、池读写与
  计算共享 B_HBM，N 路均分）；远端端口单事务 FIFO（λ_rem + 字节/B_rem）；
  拥塞感知网络 + 维度序路由；远端写回在源端收到确认后才物理释放空间；节点带
  HBM 计费模式标记（读/写/过路），每字节在正确端点计费一次。
- **可观测指标**：逐请求的亲和原因（首请求/驻留/远端）与 HBM 等待时长、三级
  状态转移流（半层化/整体外迁/后缀恢复/全量恢复的次数与字节）、逐会话 KV 层级
  快照、逐 NPU 分层账本、边缘端口队列统计、重算口径与截断丢弃量、逐请求时延与
  吞吐、决策与图的摘要校验值。

## 7. 策略小结

| 维度 | 做法 |
| --- | --- |
| P/D 组织 | 同实例一次映射，i_D = i_P，无 P→D 迁移 |
| 候选集 | 逐 NPU HBM 可行性；按会话状态分流：首请求 → 内部实例；片上/部分 → 驻留实例（粘性）；远端 → 边缘实例 |
| 负载目标 | L_run + L_queue + L_decode（Roofline 逐块/逐 token，平均生成长度为冻结常数） |
| 平局规则 | （L_i， 最近承接时刻， 实例编号）字典序最小 |
| 等待语义 | 目标集不可行 → 等待重试，候选集永不扩大；空实例也放不下才报错 |
| KV 层次 | 完整片上 / 前缀片上+后缀远端 / 完整远端，三级 |
| 层划分 | 前 ⌈L/2⌉ 层驻留，后 ⌊L/2⌋ 层首迁 |
| 淘汰 | 类型化两阶段 FIFO：（完成时刻， 会话标识），逐 NPU 收敛，活跃保护 |
| 恢复 | 按需（非预取）：部分驻留只拉后缀（与前缀计算流水重叠），远端全量拉回经最近边缘端口 |
| 历史感知 | **显式**——KV 位置是映射的第一约束 |

一句话概括：**把"KV 在哪里、放不放得下、还剩多少活"合并为 Prefill 准入时的
一次决策：首请求从内部实例起步、历史粘住驻留实例、远端历史回边缘实例；P/D 同
实例消除交接迁移，三级冷热与两阶段逐出维持这一亲和体系的容量循环。**

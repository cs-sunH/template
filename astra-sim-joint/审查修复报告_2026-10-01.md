## 二、P1/P2 语义缺陷（择要，全清单见 PROVENANCE §51/§51.5）

### SLO 工具链（joint 生产端演进后消费端未同步）
- `kv_cache_adapter` joint 映射沿用 S3：hit_state 全部落 `not_supported`（命中率假 0.0）；事件提取缺 prefill 逐腿/逐出与 decode 分支（PD/EVICTION 族漏记、`--reconcile` 假红）→ 新 `_hit_state_joint`（stay/copy→full、remote-read→partial、recompute→miss、turn-0→no_history）+ `extract_events_joint` 三分支与 native 臂同 choke point。
- `metrics_manifest` 无 digest → postprocess auto-group"绝不混组"守卫结构性失效 → plan_materializer 写 `trace_digest`/`request_mapping_digest`（sha256）。
- metrics_postprocess 同 run_id 重复输入不去重（行翻倍）→ 去重；microbench 裸 int() → 严格整型（接受 C++ u128 字符串形态）。

### 调度器/账本核心
- `work_ledger._work_from_event` 读不存在的嵌套 identity 键——decode 代际/操作静默丢弃、work_id 与字典键分叉 → 改读载荷顶层 kCarry 面。
- `_train_span_iterations` 漏计 D10 重建 span：recompute joiner × remote-read credit 成员同列车（合法组合）布局断言必炸 → 重建 span 随成员首迭代入首体块。
- W10 hybrid 的 U 迁移腿被 credit 块 1 覆写丢弃（图/账本分歧）→ joiner 槽组多腿元组逐腿发射。
- 配额重选硬编码 joint argmin——quota × J-off 合法臂选点面漂移 → `_quota_reselect_feasible` 按模式分派。
- distributed 三处：留存段恢复换实例写回旧键（键/值身份分叉）；容量终态审计漏通道 E（必误报）；混合形态目录条目 token 域错位（S 单元格无覆盖）→ 逐一修复（后者经 R3/R4 两轮加固：`_ledger_covers_suffix` 探测 + I 段自洽下限）。
- `recompute_in_place` 分支丢弃已提交逐出（池写回传输/流注册漏发）；copy 分支 evictions 未绑定 NameError 面。
- eta 槽位方向倒置（时间倍数塞进效率乘子槽，A17'(d) 恒 1.0 掩盖）→ 1/factor 换算。
- MetricCollector M-14 守卫 manifest 半边失明（动态注册可静默重绑 id）。
- `_background_links` 遥测视图丢在册半边（乐观计价）；双缓冲递推 T_{j-2} 门控（应 F_{j-2}）；义务路径缓存不按 (src,dst) 取键。
- settlement 门失败键跨请求污染 + 闭合不 bump 纪元。

### C++ 仿真核
- **custom 集合通信机制整体退役**：注释宣称的 `reject_retired_custom_key` 从不存在（fail-open，退役键静默生效）→ 按母本终态完整退役（Lookup/Impl/Sys/Topology/RecvPacket/目录/CMake），连带修复 DataSet 流数错配（custom 单流 vs 多流计数挂死）等被掩盖缺陷。
- All_Gather 小载荷 chunk=0 UB；零相 collective 静默挂死（R2 发现 R1 修复无效：notify 早于 set_notifier → DataSet 就地补发）；全集群分支 impl 计数无校验（越界读）；PacketBundle local_mem_bw 除零；queues_per_dim 零元素 SIGFPE。
- EventQueue `schedule_event` Release 下过去时间 fail-open（M-2 只镜像了 cancellable 版）→ 同款门。
- MultiDimTopology 环维度基数 1 自环幽灵链 → 退化跳过（前端 edge 复刻同步）。
- GraphBatchCommitter preflight 缺 M-9 自环镜像（生产 `SH_ONLINE_VALIDATE=0` 路径不设防）；DecisionBridge 三处 `.value()` 类型不符裸 terminate。
- MetricCollector node_events/peaks 类型守卫；heatmap read-before-write 寿命下溢。
